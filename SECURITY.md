# Security

## Report a problem
If you find a bug that could cause data loss or expose data, do not open a public issue. Use GitHub's "Report a vulnerability" button on the Security tab of this repo. If that is not available, open an issue that says only "security contact needed" and no details, and we will reply.

You can expect a first reply within 7 days.

## What the app does
- Reads only the folders you choose.
- Moves files to the Trash only. It never deletes for good.
- Makes no network connections and sends no data.

## Supported versions
Only the latest release gets fixes.
